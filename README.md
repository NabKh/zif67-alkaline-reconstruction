# ZIF-67 on nickel foam — DFT analysis

Code and relaxed structures for a DFT study of ZIF-67 grown in situ on nickel
foam, and of what the framework turns into once it meets alkaline electrolyte.

The starting question was whether the framework is even the catalyst. It is not:
under operating conditions it hydrolyses, and what is left takes up nickel from
the substrate. So most of the work here is about the reconstruction product —
its stability, its OER and HER energetics, and how its electronic structure
shifts as Ni goes in.

## Layout

```
zif67/            analysis package
  vaspio.py       readers for VASP output
  thermo.py       free-energy corrections and electrochemical references
  bulk.py         framework hydrolysis and Co/Ni mixing
  oer.py          oxygen evolution free energies and overpotential
  her.py          hydrogen adsorption and water dissociation
  electronic.py   band gaps, band centres, active-site redox cycle

figures/          plotting, kept separate from the analysis
  style.py        figure style and colour palette
  measured.py     experimental and literature values used in the figures
  benchmarks.py   convergence and spin-state test results
  make_figures.py panel definitions and figure assembly

setup/            construction of the systems, run before any DFT
  build_zif67.py      ordered ZIF-67 cell from the experimental refinement
  make_inputs.py      VASP inputs for the molecules, bulks and framework
  make_slabs.py       OER and HER surface models and their adsorbates
  make_convergence.py ENCUT and k-mesh test sets

inputs/           INCAR, KPOINTS, POSCAR and POTCAR_SPEC for every calculation
structures/       relaxed geometries (.vasp and .cif) with per-atom moments
```

`structures/MANIFEST.csv` is the index: formula, atom count, total energy, total
moment, whether it converged, and the residual force.

## Running it

The outputs are far too large to ship, so point the code at wherever the
calculations live:

```bash
pip install -r requirements.txt

python -m zif67 --root /path/to/calculations oer
python -m zif67 --root /path/to/calculations all

python figures/make_figures.py --root /path/to/calculations --outdir output
```

Everything is parsed from `OUTCAR`, `OSZICAR` and `DOSCAR` on each run. Nothing
is cached in a table, which is deliberate — cached numbers drift away from the
calculations behind them and nobody notices until much later.

## Rebuilding the systems

`inputs/` and `structures/` are the finished article; `setup/` is how they were made.
Run these in order to regenerate every model from the source refinement:

```
python setup/build_zif67.py                     # ordered ZIF-67 from COD 4124528
export MP_API_KEY="..."                         # Materials Project, for the bulk phases
python setup/make_inputs.py molecules           # H2, H2O, Hmim
python setup/make_inputs.py bulks               # CoOOH, Co(OH)2, Co3O4, Co
python setup/make_inputs.py zif67               # framework, FM and AFM
python setup/make_slabs.py                      # OER and HER slabs, adsorbates, mixing cells
python setup/make_convergence.py <ref_dir> <out_dir>
```

`structures/COD_4124528_ZIF-67.cif` is the source refinement, redistributed here
because the Crystallography Open Database places its data in the public domain.
The experimental cell carries methyl-hydrogen rotational disorder, so
`build_zif67.py` selects one rotamer per methyl group before anything else runs.

`make_slabs.py` imports `make_inputs.py`, so MAGMOM, the LDAU array ordering and the
POTCAR sequence are generated by the same code for slabs as for bulks. That is
deliberate: those three are where surface calculations most often drift away from
the bulk reference they are supposed to be compared against.

## Pseudopotentials

POTCARs are licensed and cannot be redistributed. Each directory has a
`POTCAR_SPEC` listing the PAW potentials and the order to concatenate them:

```
potpaw_PBE.54/Co/POTCAR
potpaw_PBE.54/Ni_pv/POTCAR
potpaw_PBE.54/H/POTCAR
potpaw_PBE.54/O/POTCAR
```

With a VASP licence, `cat` in that order rebuilds it.

## Settings

Spin-polarised, PAW, PBE + D3(BJ), 520 eV cutoff. DFT+U in the Dudarev scheme,
U_eff = 3.32 eV on Co and 6.20 eV on Ni — the Materials Project values, so the
energies stay compatible with its aqueous stability data. Γ-centred meshes at
0.25 Å⁻¹ for bulk; Γ-only for the framework and for isolated molecules, which sit
in 15 Å cubic boxes. Forces to 0.02 eV Å⁻¹, electronic convergence 10⁻⁶ eV,
Gaussian smearing 0.05 eV. Energies are converged to better than 4 meV/atom
against both the basis and the mesh.

Slabs: four layers, lower two fixed at bulk positions, ≥15 Å vacuum, adsorbates on
one side, dipole correction normal to the surface.

The ZIF-67 starting geometry came from an experimental single-crystal refinement,
pre-relaxed with MACE-MP-0 carrying the same D3(BJ) correction because X-ray
hydrogen positions are systematically short. That affects the starting point only
— everything reported is from the DFT relaxation.

## Magnetic initialisation — read this first

Cobalt spin states here are not determined by the geometry, and an unseeded run
will happily converge to something metastable a few tenths of an eV up. Every
configuration was seeded by hand and the alternatives relaxed separately. Three
cases caused real trouble.

The `*O` intermediate is the bad one. Left to itself it goes to an oxygen radical
with −0.77 μ_B on the adsorbed O, 1.14 eV above the Co(IV)=O oxo. Both are in
`structures/oer_slabs/` if you want to compare; only the oxo is used. `*OH → *O`
is potential-determining, so getting this wrong moves the overpotential by over a
volt — which is how it was noticed.

β-Co(OH)₂ has to relax without symmetry. Impose exact P-3m1 and the minority t₂g
manifold of high-spin d⁷ Co(II) goes degenerate, the orbital ordering disappears,
and you get a metal 0.82 eV per formula unit too high.

Last one: if you constrain the total moment, the constraint has to match the
parity of the electron count. An even constraint on an odd-electron cell is not a
spin state that exists, and VASP will return an energy above the true ground
state without complaining.
